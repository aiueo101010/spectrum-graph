# スペクトルグラフメーカー

分光光度計のテキストファイルを何本でも重ねて、線の色・種類・太さ、軸の名前と範囲を自由に決めて、Excelのグラフ（またはPNG画像）にするツールです。

**使う：** https://aiueo101010.github.io/spectrum-graph/

- 作成されるグラフはレポートに貼る大きさで作られるため、仕上がりに近い大きさで確認できるパソコンでの利用をおすすめします（スマホでも使えます）。
- 図の見た目を「標準（Excel風）／論文風（枠と目盛）／白黒（線種で区別）」から選べます。
- 読み込んだスペクトルや設定はブラウザに自動保存され、次に開いたときも前回の続きから使えます。
- ログイン不要。処理はすべてブラウザの中で行い、読み込んだファイルはどこにも送信されません。
- グラフ上をドラッグ（スマホは指）すると表示範囲が上下に動きます。凡例の上からドラッグすると凡例を好きな位置に移動できます。表示範囲は軸の数値でも変えられます。範囲は各軸の「自動に戻す」でデータに合わせた状態に戻ります。
- サンプルは架空のBTBスペクトル6本です。
