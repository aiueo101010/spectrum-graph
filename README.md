# スペクトルグラフメーカー

分光光度計のテキストファイルを何本でも重ねて、線の色・種類・太さ、軸の名前と範囲を自由に決めて、Excelのグラフ（またはPNG画像）にするツールです。

**使う：** https://aiueo101010.github.io/spectrum-graph/

- ログイン不要。処理はすべてブラウザの中で行い、読み込んだファイルはどこにも送信されません。
- 凡例はドラッグ（スマホは指）で好きな位置に移動できます。表示範囲は「拡大」「縮小」ボタンや軸の数値で変えられます（スマホは2本指でも拡大縮小）。範囲は各軸の「自動に戻す」でデータに合わせた状態に戻ります。
- サンプルは架空のBTBスペクトル6本です。
